# Languages (English / Canadian French)

- Toggle (EN / FR) in the header and on the passcode / profile screens. Default comes from `navigator.language` (`fr*` is French), the choice is saved in `localStorage` (`r6tp.lang`), `<html lang>` follows (`en` / `fr-CA`), and the change is announced politely. `?lang=pseudo` turns on a pseudo-locale (accents, about 30% longer text, wrapped in ⟦ ⟧) for finding leaks and layout problems.
- French is informal ("tu"). Messages live in `src/i18n/messages/` (ICU-style: placeholders, plurals, lists, selects). Pure code returns message descriptors that components translate; API errors are ids (`error.db.*`).
- Never translated: player names, Ubisoft usernames, official operator names, user-written text.
- Checks (`npm test`): same keys and placeholders in both languages, no unused or missing keys, no "vous/votre/vos", no hardcoded JSX text / aria-label / title / placeholder / alt (`scripts/i18n-scan.mjs`), every message renders in en / fr / pseudo. Run `node scripts/i18n-keys.mjs` for key references.
