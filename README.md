# R6 Team Planner

A Rainbow Six Siege team planner for a five-player squad: roll operators, pick a map and bomb site, and check which tactics fit the lineup.

> Full setup instructions are coming in a later step.

## Quick start

```bash
npm install
cp .env.example .env   # fill in your Supabase values
npm run dev
```

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build to `dist/` |
| `npm test` | Run the Vitest suite |
| `npm run lint` | Lint with ESLint |
